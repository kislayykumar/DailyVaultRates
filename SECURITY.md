# Security Policy

## Supported Versions

We actively issue security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of **DailyVaultRates** seriously. If you discover a security vulnerability or sensitive security issue, please do **NOT** open a public issue.

Instead, please report security vulnerabilities directly to the primary maintainer:

- **Maintainer:** Kislay Kumar (@kislayykumar)
- **Contact:** Open a private security advisory or contact directly via GitHub.

We will acknowledge receipt of your vulnerability report within 24 hours and provide regular updates regarding resolution.
